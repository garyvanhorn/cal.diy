Quickly share your meeting links with Raycast. Requires [Raycast.com](https://www.raycast.com/) to be installed and the scheduling extension from the Raycast Store needs to be installed. You can create an API token in your Developer Settings, and then you can add the API Key by opening up the extension in Raycast.
